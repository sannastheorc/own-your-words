# Own Your Words

SEEDSED. An offline spelling and reading comprehension app (PWA) for adults with developmental disabilities
who can learn but were never properly taught. Grown-up games on a phone, with no login. Nothing leaves the phone.

- How it's built: [docs/DESIGN.md](docs/DESIGN.md)
- Why it's built this way: [docs/RESEARCH.md](docs/RESEARCH.md)

## Status (2026-11-02)

First version, 0.1.0. Not yet published, and not yet tried on a real phone or by a real learner. No independent review yet.

Verified in a desktop browser at phone size: `npm test` passes; the word routine, each game, Block Drop, goals,
certificates, month report and helper tools were driven through the real screens, and the app opens offline.

Still to check on his phone: saving and printing certificates through the share menu, the installed-app experience,
the device voice, and keyboard comfort. Still to check with him: whether he likes it, and whether spelling carries over to real texts.

## Run it

```bash
npm test
```

```bash
npm run serve
```

Then open http://127.0.0.1:8644/.
